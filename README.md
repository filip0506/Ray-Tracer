# Ray Tracer
Ray Tracer — 3D Programming Assignment

A simple ray tracer implemented in C++ as part of a university 3D programming assignment.

The project focuses on the fundamentals of ray tracing, including custom 3D vector mathematics, ray-object intersection tests, and image generation. It renders a scene using orthographic projection and supports four geometric primitives: spheres, planes, oriented bounding boxes (OBBs), and triangles.
Features

    Custom implementation of 3D vectors, points, and mathematical operations.
    Ray intersection tests for spheres, planes, OBBs, and triangles.
    Closest-intersection detection for overlapping objects.
    Orthographic ray casting and pixel-by-pixel rendering.
    Distinct colours for each geometric primitive.
    Image output in a standard image format.

Technologies

    C++
    C++11 / C++14 / C++17
    Custom ray tracing and vector mathematics
    No external dependencies required, except for an optional image-writing library.

An educational project exploring the core concepts behind ray tracing and 3D computer graphics.
